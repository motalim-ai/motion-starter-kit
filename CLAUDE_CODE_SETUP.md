# Claude Code Integration - Remotion Video Project

## Project Structure
- `/video` - Main Remotion project for AI video generation
- `/remotion/remotion-main` - Remotion framework source code (reference)

## Quick Start
1. Install dependencies: `cd video && npm install`
2. Run development: `npm run studio` (in video folder)
3. Render videos: `npm run render`

## Claude Code Commands
- Analyze project: `claude "analyze this project"`
- Generate video: `claude "create a video using Remotion"`
- Debug: `claude "help debug this Remotion project"`
